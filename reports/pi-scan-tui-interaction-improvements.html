Architecture and state flow

The completed design separates user intent, durable runtime work, and TUI projection. Foreground actions carry typed provenance. Long operations finish through channels instead of blocking the redraw path. Apply transaction ownership survives the wizard so abandonment cannot hide rollback results.

Routing

Mode-specific ownership

Package-only global chords stop before Pi Scan. Printable text with no modifier or SHIFT-only reaches the focused wizard field before Help.

Policy

Truthful pause feedback

A running scan produces a queued acknowledgement immediately. Durable pause state changes only after persistence succeeds under the existing orchestrator lock.

Setup

Transaction outside the wizard

The workspace retains Apply correlation and abandonment state. A later transfer rolls back through an explicit result path even after the draft closes.

Rendering

State changes before paint

Result insertion and unseen counts change in event projection. Rendering records hit rectangles and clamps presentation offsets but does not clear unseen state.

Behavior delivered

  • BackTab cycles workspace pages backward. Wizard BackTab reverses focus. Hidden Package-pane state no longer changes under Pi Scan chords.
  • Foreground and background notices cannot overwrite each other. Info and Success expire after six seconds. Warning and Error persist.
  • Results receive an unseen badge until Results is entered. Validated completion does not force a view change.
  • Active work shows elapsed time, a redraw-driven spinner, token/cost reservation, and reconciled background usage.
  • Targets and Results keep separate selections. Lists, Details, and wizard content scroll by keyboard and wheel. Result rows are clickable.
  • Help and contextual footers describe the keys that work on each page. Package mode shows running or unseen Pi Scan state only when enabled.
Intentional branch decision: Pause and Resume remain serialized with the active scan because the orchestrator mutex owns durable policy. The UI reports “queued” immediately and “persisted” only after the durability boundary. A lock-independent policy journal remains outside this branch.

How to use the finished interactions

  1. Open Pi Scan from Search with the configured shortcut, default Shift+A. Non-AUR selections now explain what to do next.
  2. Move among pages with 1–6, Tab, or BackTab. Use j/k, arrows, PgUp/PgDn, g/G, wheel input, and row clicks where listed in the footer.
  3. On Progress, use p, u, x, or r. The footer no longer advertises Detach/Reopen.
  4. On Details, use a/s/c/b/t. The t toggle switches between structured and canonical raw output for the current session.
  5. During Apply, first Esc warns. A second Esc requests abandonment and leaves the correlation active until rollback reports success or failure.

Residual risks and limits
  • Live external Pi/provider behavior was not run in this pass. Four Pi Scan checks remain deliberately ignored unless the environment is configured.
  • Display-width scroll bounds approximate Ratatui's private wrapping for unusual grapheme and whitespace combinations.
  • Timed-out setup helper threads may finish after the controller returns, but their bounded late results have no sender and cannot mutate runtime ownership. Owned probe processes still use terminate-and-reap deadlines.
  • The two micro-USD parsers are equivalent today but remain a maintenance duplication.
  • The spinner advances on wall-clock seconds. This is enough to show liveness but not every redraw.
