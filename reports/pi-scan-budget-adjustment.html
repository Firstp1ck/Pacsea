Design and user flow

Semantics

Zero is not a zero-dollar stop

A stored 0 or 0.00 skips that one finite comparison. Other limits and all consent, service, user-pause, setup, and platform gates still apply.

Double

Exact, affected-only growth

Double uses checked multiplication on only the dimensions currently exceeded. If one doubling is still too small, the Budget pause remains and the UI names the residual limit.

Unlimited

Explicit spending warning

Unlimited writes zero only to affected dimensions. The dialog warns that paid background calls may continue until separately paused.

Usage and rollout

1

Open the paused workspace

Use Overview or Progress. A Budget pause with queued background work makes the direct action eligible.

2

Press b

The focused dialog shows every currently affected limit and the proposed old-to-new values. Double is selected initially.

3

Choose and confirm

Use Tab, arrows, or Vim movement keys to choose Double or Unlimited. Press Enter to apply, or Esc to cancel before submission.

4

Read the result

If Double is insufficient, the queue stays paused and the residual limits are named. Unlimited removes only the affected budget ceilings. Other policy gates continue to apply.
