How to use it

1. Open the package result

Select the package in Results and open Details.

2. Review and continue

Press c or click [c] Review & continue. Existing a and s shortcuts still record finding and stale-identity acknowledgements directly.

3. Read the popup

The popup states which acknowledgements are still pending and lists the identity recheck, stop-on-change behavior, return to the package list, and normal preflight.

4. Confirm or cancel

Use Enter or y to confirm. Use Esc, q, or n to cancel without changing acknowledgement state. Use j/k, arrows, or PgUp/PgDn to scroll narrow popups.
