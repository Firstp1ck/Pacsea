Integrated config editor: suggestions, keybind recording, denser layout

Pacsea's in-TUI config editor (AppMode::ConfigEditor) was redesigned for usability on branch feat/config-editor-ux (worktree, based on local feat/aur-scan-integrated @ 29351805). Evidence comes from the canonical plan, worker handoffs, two independent reviews, the integration owner's own check runs, and frames rendered through pacsea::ui::ui on a ratatui TestBackend.

Conclusion: Every editable setting now opens a dropdown of suggestions with optional manual input, live validation and an explicit "Enter saves" preview. Keybinds can be recorded from a visible Record button. The editor uses file tabs, a grouped list with current values and modified markers, and a details pane. All 17 accepted review findings were fixed and revalidated. Final checks: cargo fmt, clippy -D warnings and cargo check clean, and 2,040 tests passed, 0 failed. The work is staged, not committed.

Confidence: High for behavior covered by unit, render and integration tests. Not yet exercised in a live terminal with real mouse input. German strings have not had a native-speaker review; Hungarian uses English placeholders by project convention.

Risks & next steps

Open

No live terminal run

Rendering and input were verified with TestBackend and the public event dispatcher, not in a real terminal with mouse. Terminal-specific chord reporting (e.g. Shift+letter) is unexercised.

Behavior change

Changed muscle memory

b no longer stars (use Ctrl+B); Esc with an empty search leaves the editor; ↑↓ no longer nudge integers (use +/-). Footer and Help describe the new keys.

Known limit

Multi-chord keybinds

The editor writes one chord per action. For recent_remove/install_remove, config lines append to defaults, so the old chord keeps working; the row now shows ● and +N.

Merge

Shared locale files

The main checkout is editing Pi Scan sections of the same YAML files. This branch only touches app.modals.config_editor.* and the editor help lines, so conflicts should be limited to nearby lines.

Translation

Language quality

German strings were written by the implementation agent and not reviewed by a native speaker; Hungarian carries English placeholders flagged for translation.

Deferred

Minor cosmetics

Long values in the details pane wrap at character, not word, boundaries; the footer is built up to three times per frame (cheap).
