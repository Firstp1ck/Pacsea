Approved design

The user selected balanced sections, 12-character hashes outside Technical Details, coverage of both advanced Setup and the guided wizard, and semantic color that never carries meaning alone.

Active

Sapphire

Selected rows, current work, focused controls, and direct actions. Text, arrows, checkboxes, or spinner symbols accompany the color.

Success

Green

Connected, current, complete, confirmed, and finished states. Each retains an explicit status word or check mark.

Attention

Yellow

Pending, paused, incomplete, disabled, and warning states. Pause and warning symbols remain visible without color.

Failure

Red

Failed, disconnected, stale, high, and critical states. Labels remain readable in monochrome output.

Identity rule: package names and status lead every human-facing row. Commit IDs use a deterministic 12-character prefix outside Technical Details. Scanner state and the expanded Details technical section retain the exact full identity.

Implementation path

  1. Shared visual system and Setup surfaces

    mod.rs gained shared semantic tone, label/value, section heading, short-identity, and wrapped-line helpers. Setup, the wizard, and Overview adopted the new hierarchy.

  2. Target, progress, and result surfaces

    Targets and Results now render one bounded visual row per item with matching mouse seams. Progress separates summary, current work, and queue content.

  3. Validated review fixes

    Wrapped wizard clicks, completed notice styling, German Results wording, and German Setup validation text each received a failing regression before the fix and a passing rerun afterward.
